# GeeksforGeeks Problem of the Day

A collection of C++ solutions to GeeksforGeeks Problem of the Day challenges.

## Purpose

This repository tracks daily algorithm practice and provides a place to revisit common data structures and problem-solving techniques.

## Suggested solution format

For each solution, include:
- Link to the original problem
- Brief approach or key insight
- Time complexity
- Space complexity

## Language

- C++

## Compiling a solution

Use a C++17-compatible compiler and adapt the command to the source filename:

```bash
g++ -std=c++17 -O2 -Wall -Wextra solution.cpp -o solution
./solution
```

Some GeeksforGeeks problems use a platform-provided driver or class signature, so the code may need to be submitted through the original problem interface rather than run as a standalone program.
